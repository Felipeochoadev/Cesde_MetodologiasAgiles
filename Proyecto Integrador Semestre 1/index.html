Matriz de Lógica y Condicionales

Para la clase de Lógica de Programación, el sistema evalúa los datos combinando los siguientes factores y operadores lógicos:

Validación / Regla Operador Lógico Condición en JS Efecto en el Sistema
Campos Vacíos OR (||)
NOT (!)		 if (!nombre || !boletos || !edad) Muestra error si falta al menos un dato obligatorio.
Control de Boletos Menor Igual (<=) if (boletos <= 0) Bloquea números negativos o compras en cero.
Restricción de Edad AND (&&) if (pelicula === "4" && edad < 18) Bloquea la reserva únicamente si se cumplen ambas premisas.
Descuento (10%) OR (||) if (boletos > 4 || edad < 12) Aplica el descuento si lleva muchos boletos ó si es un niño.
💡 Nota Académica: El operador && requiere que todas las condiciones sean verdaderas para ejecutar el bloque, mientras que el operador || se ejecuta si al menos una de las condiciones es verdadera.
